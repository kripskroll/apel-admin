    Connexion à GitHub

    Pour téléverser des images, il faut un jeton GitHub (Personal Access Token, PAT). Une seule fois par appareil.

    1. Ouvrez la page de génération du jeton (connectez-vous au compte partagé de l'association).
    2. Resource owner : le compte de l'association. Repository access : Only select repositories → choisissez apel-images.
    3. Repository permissions → Contents : Read and write. Laissez les autres sur No access.
    4. Validez, copiez le jeton (commence par github_pat_…), et collez-le ci-dessous.

    Versions du site sur GitHub

    Cliquez sur une version pour la charger dans l'éditeur. Vous pourrez ensuite la modifier puis « Sauvegarder » pour la remettre en avant.
