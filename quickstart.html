🚀 Démarrage rapide

Tout ce qu'il faut savoir pour utiliser l'éditeur APEL en 5 minutes.

1Première connexion à GitHub

L'éditeur sauvegarde le site sur GitHub. Pour cela, il a besoin d'un jeton d'accès (PAT). À faire une seule fois par appareil.

Étape 1.1 — Ouvrez github.com/settings/personal-access-tokens/new dans un nouvel onglet (connectez-vous au compte GitHub partagé de l'association si demandé).

Étape 1.2 — Remplissez le formulaire ainsi :

github.com/settings/personal-access-tokens/new
Token name
APEL admin
Expiration
Custom → choisissez une date dans 11–12 mois
Repository access
⦿ Only select repositories → apel-images + apel-site
Repository permissions → Contents
Access: Read and write
Laissez toutes les autres permissions sur No access.

Étape 1.3 — Cliquez sur Generate token, puis copiez le jeton qui commence par github_pat_… (il ne s'affichera qu'une seule fois).

Étape 1.4 — Ouvrez l'éditeur APEL. Cliquez sur le bouton Connexion en haut à droite.

Une fenêtre s'ouvre. Collez votre jeton et validez :

Connexion à GitHub

Pour téléverser des images, il faut un jeton GitHub (Personal Access Token, PAT). Une seule fois par appareil.

  1. Ouvrez la page de génération du jeton…
  2. Resource owner / Repository access…
  3. Repository permissions → Contents : Read and write
  4. Collez le jeton ci-dessous
Annuler Se connecter
Bon à savoir. Le jeton reste dans votre navigateur (zone localStorage) — il ne quitte jamais votre Mac. À la prochaine ouverture de la page, vous êtes déjà connecté.

2La page se charge automatiquement

L'éditeur récupère la dernière version du site depuis GitHub à chaque ouverture. Pendant quelques secondes, vous voyez l'écran d'accueil.

⏱️ Soyez patient : le fichier du site fait ~2 Mo et son chargement initial prend environ 10 secondes. C'est normal — ne rechargez pas la page.

Une fois le chargement terminé, vous arrivez sur l'éditeur, avec la liste des articles à gauche, le formulaire d'édition au centre, et un aperçu à droite :

3Modifier un article

Cliquez sur un article à gauche pour le sélectionner, puis modifiez les champs au centre. Toutes les modifications sont gardées en mémoire jusqu'à la sauvegarde.

Champs principaux d'un article :

  • Titre (en rose) — le titre principal de l'article.
  • Sous-titre (en turquoise) — optionnel.
  • Image — URL raw.githubusercontent.com. Utilisez le bouton 📎 Importer à côté du champ pour téléverser une image depuis votre Mac (elle ira automatiquement sur GitHub).
  • Corps du texte — éditeur riche avec gras, italique, couleurs, listes, liens.
  • Bouton — optionnel : texte + URL si l'article doit afficher un bouton d'action.
  • Date et Statut (Publié ou Brouillon).
Astuce. Pour réordonner les articles, faites glisser-déposer dans la liste de gauche (icône ⋮⋮). L'ordre dans la liste = l'ordre sur le site.

4Sauvegarder

Le bouton 💾 Sauvegarder en haut à droite déclenche deux actions en même temps.

  1. Téléchargement local d'un fichier apel-site-AAAA-MM-JJ.html dans le dossier Téléchargements de votre Mac. Ce fichier est ce que vous enverrez au webmaster de l'école.
  2. Commit GitHub qui met à jour la version officielle. Confirmation en bas : « ✅ Sauvegardé : téléchargement + commit GitHub abc1234 ».
⚠️ N'oubliez pas d'envoyer le fichier téléchargé au webmaster de l'école pour qu'il le mette en ligne. Le commit GitHub ne met pas le site en ligne automatiquement — c'est juste une sauvegarde versionnée.

5Bonus : revenir à une ancienne version

Chaque sauvegarde crée un commit sur GitHub. Vous pouvez restaurer n'importe quelle version précédente.

  1. Cliquez sur 📂 Changer de fichier en haut à droite pour revenir à l'écran d'accueil.
  2. Cliquez sur 🕓 Charger une ancienne version (GitHub).
  3. Une liste de toutes les sauvegardes s'affiche, avec date et heure. Cliquez sur celle que vous voulez restaurer.
  4. Une bannière jaune apparaît en haut de l'éditeur : « Version historique — sauvegarder écrasera la version actuelle. »
  5. Si tout est bon, cliquez sur 💾 Sauvegarder pour faire de cette version la nouvelle version officielle.
