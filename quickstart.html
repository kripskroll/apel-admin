🚀 Démarrage rapide

Tout ce qu'il faut savoir pour utiliser l'éditeur APEL en 5 minutes.

📖 Guide d'utilisation 📝 Démarrer l'éditeur →

1Se connecter (première fois uniquement)

La toute première fois que vous utilisez l'éditeur sur un ordinateur, vous devez coller un code de connexion. Votre administrateur APEL vous l'a transmis.

Le code ressemble à une longue chaîne de caractères qui commence par github_pat_. C'est normal qu'il soit aussi long — c'est ce qui permet à l'éditeur d'enregistrer vos modifications en ligne, en toute sécurité.

  1. Ouvrez l'éditeur APEL.
  2. En haut à droite, cliquez sur le bouton Connexion.
  3. Une fenêtre s'ouvre. Collez votre code dans le champ prévu :

Connexion à GitHub

Pour téléverser des images, il faut un jeton GitHub (Personal Access Token, PAT). Une seule fois par appareil.

Annuler Se connecter

Cliquez sur Se connecter. Le bouton en haut devient vert et affiche votre nom de connexion. C'est fait — vous n'aurez plus à le faire sur cet ordinateur.

🔒 Ne partagez pas ce code à l'extérieur de l'équipe. C'est l'équivalent d'un mot de passe. Si vous l'avez perdu ou si quelqu'un d'extérieur l'a vu, demandez-en un nouveau à votre administrateur APEL.

2Patientez quelques secondes au chargement

À chaque ouverture, l'éditeur récupère la dernière version du site. Cela prend environ 10 secondes.

⏱️ Ne rechargez pas la page pendant ce temps. L'écran d'accueil reste affiché brièvement, c'est normal.

Une fois le chargement terminé, vous arrivez sur l'éditeur. À gauche, la liste des articles. Au centre, le formulaire d'édition. À droite, un aperçu en direct.

3Modifier un article

Cliquez sur un article à gauche pour l'ouvrir. Modifiez les champs au centre. L'aperçu à droite se met à jour automatiquement.

Pour ajouter une image : cliquez sur le bouton 📎 Importer à côté du champ Image et choisissez une image sur votre ordinateur. C'est tout — l'éditeur s'occupe du reste (compression, téléversement, URL).

Astuce. Pour réordonner les articles sur le site, faites glisser-déposer dans la liste de gauche (avec l'icône ⋮⋮). L'ordre dans la liste = l'ordre d'affichage sur le site.

4Sauvegarder et envoyer au webmaster

Quand vous avez fini vos modifications, cliquez sur 💾 Sauvegarder en haut à droite.

Deux choses se passent automatiquement :

  1. 📥 Un fichier apel-site-AAAA-MM-JJ.html arrive dans votre dossier Téléchargements.
  2. ☁️ Une copie de sécurité est sauvegardée en ligne (vous pourrez la récupérer plus tard si besoin — voir étape 5).
📧 N'oubliez pas l'étape finale : envoyez le fichier téléchargé (apel-site-AAAA-MM-JJ.html) par e-mail au webmaster de l'école pour qu'il le mette en ligne sur le site.

5Bonus : revenir à une version précédente

Toutes vos sauvegardes sont conservées en ligne. Si vous voulez annuler des changements et restaurer une version plus ancienne, c'est possible.

  1. Cliquez sur 📂 Changer de fichier en haut à droite (vous revenez à l'écran d'accueil).
  2. Cliquez sur 🕓 Charger une ancienne version.
  3. Choisissez la date que vous voulez restaurer.
  4. Une bannière jaune vous prévient que vous regardez une ancienne version.
  5. Si tout est bon, cliquez sur 💾 Sauvegarder pour faire de cette version la nouvelle version officielle.

👉 Pour plus de détails sur chaque fonctionnalité, consultez le guide d'utilisation.

C'est tout !

Vous êtes prêt à utiliser l'éditeur APEL.
