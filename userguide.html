1. À quoi sert l'éditeur

L'éditeur APEL est une page web qui permet à 2-3 personnes de l'association de mettre à jour les articles du site sans connaissances techniques. Vous voyez en direct ce que ça donnera sur le site, vous sauvegardez, et vous envoyez le résultat au webmaster de l'école par e-mail.

Ce que vous pouvez faire :

  • Modifier les articles existants (titre, sous-titre, texte, image, bouton, date, statut).
  • Ajouter de nouveaux articles.
  • Supprimer des articles.
  • Réordonner les articles par glisser-déposer.
  • Téléverser une image depuis votre ordinateur — elle est automatiquement compressée et hébergée pour vous.
  • Revenir à n'importe quelle version précédente du site si vous voulez annuler des changements.
Plusieurs personnes, une seule version. Les 2-3 personnes de l'équipe APEL travaillent toutes sur le même site partagé. Quand l'une d'entre vous sauvegarde, les autres récupèrent automatiquement la nouvelle version au chargement suivant.

2. Se connecter la première fois

L'éditeur enregistre vos modifications sur un service en ligne sécurisé. Pour autoriser votre ordinateur à enregistrer, il faut une seule fois coller un code de connexion que votre administrateur APEL vous a fourni.

2.1 Le code de connexion

Le code est une longue chaîne de caractères qui commence par github_pat_. Par exemple :

github_pat_11ABCDEFG0xxxxxxxxxxxxx_yyyyyyyyyyyyyyyyyyyyyyyyyyyyyy

C'est l'équivalent d'un mot de passe d'application. Toute l'équipe APEL utilise le même code — votre administrateur s'occupe de le distribuer.

🔒 Ce code est confidentiel. Ne le partagez pas en dehors de l'équipe APEL (pas de copie sur les réseaux sociaux, e-mails publics, etc.). Si vous pensez qu'il a été compromis, prévenez votre administrateur — il en générera un nouveau.

2.2 Coller le code dans l'éditeur

En haut à droite de l'éditeur, vous voyez la barre de connexion :

kripskroll.github.io/apel-admin/
Non connecté Connexion
Synchronisé
💾 Sauvegarder

Cliquez sur Connexion. Une fenêtre s'ouvre :

Connexion à GitHub

Pour téléverser des images, il faut un jeton GitHub (Personal Access Token, PAT). Une seule fois par appareil.

Annuler Se connecter
  1. Collez votre code dans le champ.
  2. Cliquez sur Se connecter.
  3. La barre devient verte et affiche un nom d'identifiant. C'est fait.
Une seule fois suffit. Le code est mémorisé par votre navigateur. Tant que vous ne vous déconnectez pas et que vous ne videz pas les données du navigateur, vous restez connecté.
🖥️ Si vous utilisez un autre ordinateur (par exemple votre Mac à la maison et celui de l'association), il faudra refaire la connexion sur chaque ordinateur. Mais une seule fois par ordinateur.

3. Chargement de la page

À chaque ouverture de l'éditeur, la dernière version du site est récupérée automatiquement. C'est ce qui garantit que vous travaillez toujours sur la version la plus à jour, même si quelqu'un d'autre a modifié quelque chose depuis votre dernière visite.

Le délai d'attente

Le fichier du site est un peu volumineux (environ 2 Mo), donc son chargement prend environ 10 secondes. Pendant ce temps, vous voyez un écran d'accueil :

A
Éditeur d'articles APEL
Chargement en cours…
⏱️ Ne rechargez pas la page pendant ces 10 secondes — vous repartiriez de zéro. Si l'écran d'accueil reste affiché plus de 20 secondes, voir Problèmes courants.

4. Modifier un article

4.1 Sélectionner un article

Cliquez sur un article dans la liste de gauche. Le formulaire central se remplit avec ses données, et l'aperçu à droite se met à jour en direct.

4.2 Les champs disponibles

ChampDescription
TitreLe titre principal de l'article. Affiché en rose sur le site.
DateDate affichée à côté du titre, et sert au tri.
StatutPublié = visible sur le site. Brouillon = caché, visible uniquement dans l'éditeur.
Sous-titreAffiché en turquoise sous le titre. Optionnel.
ImageL'image principale de l'article. Voir section 5.
Corps du texteLe contenu de l'article. Vous pouvez mettre du gras, italique, des listes, des liens, et utiliser les couleurs rose/turquoise.
BoutonOptionnel : un bouton d'action (ex. « S'inscrire », « En savoir plus ») qui pointe vers une page externe.

4.3 Créer, supprimer, réordonner

  • Créer : bouton + Nouvel article en haut de la liste. Il apparaît tout en haut, statut Brouillon par défaut.
  • Supprimer : icône 🗑 sur l'article dans la liste. Une confirmation est demandée.
  • Réordonner : glissez-déposez les articles dans la liste (utilisez l'icône ⋮⋮ à gauche de chaque article). L'ordre dans la liste = l'ordre sur le site.
L'indicateur orange « ● Modifications non sauvegardées » apparaît en haut dès que vous modifiez quoi que ce soit. Tant qu'il est affiché, vos changements ne sont pas enregistrés. Pensez à cliquer sur 💾 Sauvegarder avant de fermer la page.

5. Ajouter une image

5.1 Importer une image depuis votre ordinateur (recommandé)

  1. Cliquez sur le bouton 📎 Importer à côté du champ Image.
  2. Choisissez une image sur votre Mac (JPG, PNG, etc.).
  3. L'éditeur compresse automatiquement l'image (qualité préservée, mais beaucoup plus légère).
  4. L'image est ensuite envoyée vers l'espace de stockage en ligne.
  5. L'adresse de l'image est automatiquement collée dans le champ. L'aperçu se met à jour immédiatement.

Pendant l'opération, des messages s'affichent en bas de la page : « Compression de l'image… », puis « Téléversement… », puis « ✅ Image téléversée ». Comptez quelques secondes selon la taille de votre image.

5.2 Coller une adresse d'image existante

Si vous avez déjà l'adresse Internet d'une image (par exemple une image trouvée en ligne), vous pouvez la coller directement dans le champ Image. L'aperçu se met à jour.

⚠️ Évitez les liens Google Drive ou OneDrive partagés : ces liens pointent vers des pages d'aperçu, pas vers l'image elle-même. Le site n'arrivera pas à afficher l'image. Utilisez plutôt le bouton Importer.

6. Sauvegarder et envoyer au webmaster

Une fois vos modifications terminées, cliquez sur 💾 Sauvegarder en haut à droite. Deux actions se déclenchent en même temps :

  1. 📥 Un fichier apel-site-AAAA-MM-JJ.html arrive dans votre dossier Téléchargements.
  2. ☁️ Une copie de sécurité est sauvegardée en ligne — c'est ce qui sera rechargé la prochaine fois que vous (ou un autre membre de l'équipe) ouvrirez l'éditeur.

Message de confirmation en bas de la page : « ✅ Sauvegardé : téléchargement + copie en ligne ».

L'étape finale : envoyer au webmaster

La sauvegarde en ligne est juste un filet de sécurité. Pour que vos modifications apparaissent sur le vrai site, il faut :

  1. Récupérer le fichier apel-site-AAAA-MM-JJ.html dans votre dossier Téléchargements.
  2. L'envoyer par e-mail au webmaster de l'école.
  3. Le webmaster met le fichier en ligne sur le serveur du site (ce n'est pas vous qui le faites).
📧 N'oubliez pas l'e-mail. Sans cet envoi au webmaster, vos modifications restent en sauvegarde mais n'apparaissent pas sur le site public.

7. Revenir à une ancienne version

Chaque fois que quelqu'un de l'équipe sauvegarde, une copie est conservée en ligne. Vous pouvez récupérer n'importe laquelle de ces copies si vous voulez annuler des changements ou retrouver un ancien article.

7.1 Voir la liste des versions

  1. Si vous êtes dans l'éditeur, cliquez sur 📂 Changer de fichier en haut pour revenir à l'écran d'accueil.
  2. Cliquez sur 🕓 Charger une ancienne version.

Une fenêtre affiche toutes les sauvegardes, de la plus récente à la plus ancienne :

Versions du site sur GitHub

Cliquez sur une version pour la charger.

7.2 Charger et restaurer

Cliquez sur la ligne correspondant à la date que vous voulez. Le contenu de cette version est chargé dans l'éditeur. Une bannière jaune apparaît en haut :

⚠️ Version historique — 28/05/2026 13:25. Sauvegarder écrasera la version actuelle sur GitHub.

Deux choix s'offrent à vous :

  • Restaurer cette version : cliquez sur 💾 Sauvegarder. Cette ancienne version devient la nouvelle version officielle (et vous récupérez aussi un fichier à envoyer au webmaster).
  • Annuler : cliquez sur Revenir à la dernière version dans la bannière jaune.
Bonne nouvelle : aucune version n'est jamais perdue. Même si vous restaurez une ancienne version, la version actuelle reste dans l'historique — vous pourriez la restaurer à son tour plus tard si besoin.

8. Se déconnecter

Si vous voulez retirer votre code de connexion de cet ordinateur (par exemple parce que quelqu'un d'autre va l'utiliser, ou parce que vous êtes sur un Mac partagé) :

  1. Cliquez sur Déconnexion dans la barre en haut.
  2. Confirmez.

Le code est effacé du navigateur. La prochaine personne devra recoller un code pour pouvoir sauvegarder.

Note : la déconnexion empêche de sauvegarder, mais on peut toujours consulter les articles (le site est public en lecture).

9. Problèmes courants

L'écran d'accueil reste affiché plus de 20 secondes

Le chargement depuis le service en ligne n'arrive pas à se terminer. Vérifiez :

  • Votre connexion Internet fonctionne-t-elle ? (essayez d'ouvrir un autre site).
  • Rechargez la page avec Cmd+R.
  • Si ça persiste, contactez votre administrateur APEL.

« Jeton invalide » ou « Code refusé »

Votre code de connexion n'est plus valide. Les codes ont une durée de vie limitée (un an environ) — il a probablement expiré. Demandez un nouveau code à votre administrateur APEL et collez-le via le bouton Connexion.

« Le fichier a été modifié entre-temps »

Quelqu'un d'autre dans l'équipe a sauvegardé une nouvelle version pendant que vous éditiez. Pour éviter de perdre son travail, l'éditeur refuse votre sauvegarde.

Que faire : rechargez la page (vos modifications locales seront perdues, malheureusement), puis refaites vos changements sur la nouvelle version. Pensez à coordonner avec votre équipe pour ne pas éditer en même temps.

L'image que je viens d'importer n'apparaît pas dans l'aperçu

Vérifiez que vous êtes bien connecté (la barre en haut doit être verte). Si l'image semble bloquée à « Téléversement… », votre connexion Internet est peut-être lente — patientez encore quelques secondes.

J'ai cliqué sur Sauvegarder mais aucun fichier n'apparaît dans Téléchargements

Vérifiez que votre navigateur n'a pas bloqué le téléchargement (icône en haut à droite de Chrome ou Safari). Cliquez sur Autoriser et réessayez.

Une question qui n'est pas listée ici

Contactez votre administrateur APEL. Si c'est un souci technique, il pourra consulter le guide administrateur.

Vous êtes prêt(e) !

Tout est dans vos mains pour faire vivre le site APEL.
